Estandarización de API: Go & Angular

Esta guía define las reglas de comunicación entre el equipo de Frontend (FE) y Backend (BE) para garantizar consistencia y reducir errores de integración.

1. Arquitectura de Modelos (Structs)

En el backend, debemos separar estrictamente los datos que viajan por la red de los datos que procesamos internamente o guardamos en la base de datos.
En otras palabras, se debe crear los Structs para request y response necesarios, ademas del struct principal que puede contener logica.

Importante:

En Go, los campos deben iniciar con Mayúscula para ser "públicos".
La etiqueta `json:"..."` le dice a Go cómo buscar esa llave en el JSON entrante.

A. Structs de Request/Response (DTOs)

Son los objetos que serializamos/deserializamos. Llevan etiquetas `json:"..."`.

// DTO para recibir datos del Frontend
type CreateUserRequest struct {
    Name     string `json:"name"`
    Email    string `json:"email"`
    Password string `json:"password"`
}

// DTO para enviar datos al Frontend (oculta información sensible)
type UserResponse struct {
    ID    int    `json:"id"`
    Name  string `json:"name"`
    Email string `json:"email"`
}

B. Struct de Lógica Interna (Dominio/BD)

Modelo utilizado para lógica de negocio o guardar en PostgreSQL. No lleva etiquetas JSON porque no se expone a internet.

type User struct {
    ID           int
    FullName     string
    EmailAddress string
    PasswordHash string
    CreatedAt    time.Time
}

C. Mapeo (Conversión entre Structs)

Nunca guardes un Request directamente en la base de datos ni expongas un modelo de BD directamente en un Response. Realiza la conversión manualmente en el controlador/servicio.

// Función de conversión de Request a Modelo de BD
func ToUserDomain(req CreateUserRequest) User {
    return User {
        FullName:     req.Name,
        EmailAddress: req.Email,
        // Aquí se aplicaría el hashing a la contraseña
        PasswordHash: req.Password, 
        CreatedAt:    time.Now(),
    }
}

2. Serialización y Deserialización en Go

Utilizamos el paquete nativo encoding/json.

  • Deserializar (JSON a Struct): Usar json.NewDecoder(r.Body).Decode(&miStruct)
  • Serializar (Struct a JSON): Usar json.NewEncoder(w).Encode(miStruct)

3. Sincronización de Modelos entre BE y FE

Dado que el BE está en Go y el FE en TypeScript, no podemos compartir el código directamente. Se aplicará el siguiente estándar:

Estrategia Contract-First:
El equipo de Backend debe generar los structs en la carpeta de modelos correspondiente en models/public. El equipo de Frontend generará sus Interfaces de TypeScript (export interface UserResponse {...}) basándose estrictamente en los structs de request response ubicados en la carpeta models/public, no en suposiciones. Cuando el BE cambie un contrato, se debe notificar mediante un Pull Request en el repositorio BE que incluya la actualización de la documentación, etiquetando a los desarrolladores de FE para su revisión.

4. Ejemplos Básicos: GET y POST

package main

import (
    "encoding/json"
    "net/http"
)

// POST: Recibir JSON, mapear a dominio y responder JSON
func CreateUserHandler(w http.ResponseWriter, r *http.Request) {
    // 1. Deserializar Request (JSON -> Struct)
    var req CreateUserRequest
    if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
        http.Error(w, "Error procesando JSON", http.StatusBadRequest)
        return
    }

    // 2. Mapear DTO a Modelo de Dominio Interno
    user := ToUserDomain(req)

    // (Simulación: Aquí user se guardaría en PostgreSQL y obtendría un ID)
    user.ID = 1 

    // 3. Mapear Modelo de Dominio a Response DTO
    res := UserResponse{
        ID:    user.ID,
        Name:  user.FullName,
        Email: user.EmailAddress,
    }

    // 4. Serializar Response (Struct -> JSON)
    w.Header().Set("Content-Type", "application/json")
    w.WriteHeader(http.StatusCreated)
    json.NewEncoder(w).Encode(res)
}

// GET: Enviar datos al Frontend
func GetUserHandler(w http.ResponseWriter, r *http.Request) {
    // (Simulación: Obtener modelo desde la base de datos)
    dbUser := User{
        ID: 1,
        FullName: "Josecarlos",
        EmailAddress: "jose@ejemplo.com",
    }

    // Mapear a DTO Response
    res := UserResponse{
        ID:    dbUser.ID,
        Name:  dbUser.FullName,
        Email: dbUser.EmailAddress,
    }

    // Enviar JSON
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(res)
}
